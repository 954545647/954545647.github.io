# 孙中山故居 · 翠亨寻迹

数据核对：2026-10-23。公开游客 ID：`sun-yat-sen`。

本包选取孙中山故居纪念馆与翠亨古村的九处核心点位：孙中山故居、孙中山纪念馆、翠亨民居展示区、杨殷故居、陆皓东故居、冯氏宗祠、杨贞义堂、警世钟、孙中山演讲厅。

- `editorial.json`：依据纪念馆官网编写的介绍、讲解和逐点事实来源。不是官方导览词。
- `scenic.json`：兼容游客站 schema 7 的素材包。
- `geography.json`、`raw/osm_*.geojson`：OpenFreeMap 的 2026-10-18 OSM 矢量数据，WGS84；保留来源和量化误差说明。
- `raw/photos_final.json`：九张逐张查看的真实照片；作者、原页、许可证、日期完整。每张照片继续遵循各自许可，不由本仓库统一改许可。
- `photos/`：Commons 提供的 1280px 缩略图。7 张 CC BY-SA 4.0，2 张 CC0（以实际元数据为准）。署名显示在每个照片详情页，另有公开的 `assets/scenics/sun-yat-sen/credits.html`。
- `map.png`：按 OSM 地理要素制作的核心区导览图，图幅是编辑裁切范围，并非景区法律边界。没有捏造水面和步行路线。

## 筛选与校对

相邻中山影视城内的“南京中山陵”和“上海孙中山故居”复制场景未收录。农场、家猪/家禽展示区、远处家族墓群、纪念中学未收录。原农耕文化展示区已于2026年8月调整管理，不据旧分类加入本包。

Commons “Ancestral Home” 文件实际展示现存故居主楼，不作为祖屋遗址照片；民居分类中的竹子、植物标牌也不作为建筑照片。民居展示区使用巷道实拍。杨殷故居两个相邻 OSM POI 合并成一处，采用北侧建筑点。高德 GCJ-02 搜索坐标不直接混入 WGS84 点位。

孙中山演讲厅讲解明确其为现有公共文化活动设施，未暗示孙中山曾在该建筑演讲。临时开放安排以官方当日公告为准。

## 重建

使用带 Pillow 和 Shapely 的 Python 运行 `python scenes/sun-yat-sen/build_scene.py`，再运行 `python tools/add_scenic.py scenes/sun-yat-sen`。`build_scene.py` 会保留 `map-package.json`，通用合并脚本也会保留 `published.mapPackage`，因此后续重建 2D 不会覆盖已接入的三维地图。

生成端源 ID：`scenic-amap-b02f802mx8`。2026-10-23 在生成端选定约717×590米范围，并提供九处点位及排除规则。源端不含公开仓库的凭据、SSO 信息或完整工作区导出。

## 生成端三维制作

生成端已发布 v1，九处地标均为 AI 制作的导览模型。不是摄影测量或历史建筑精确复原。建筑与地面尺寸细节是模型示意；纪念馆模型因包围盒冲突向西北调整约 6 米，仍在 OSM 建筑范围内。实景照片与官方讲解独立保留。

制作端总览检查报告为 17 个模型加载成功、0 个加载错误；独立视觉评审为 62 分，主要待改进项为纪念馆屋面、地表材质、水岸与入口细节。关闭了近地面云层效果，没有开启无限自动打磨。

`studio-map-package.pending.json` 保存已发布包的原始模型引用，用于核对和继续导出；游客端只使用已下载、通过验证的 `map-package.json`。用 `import_studio.py` 导入单景区发布记录和模型资源后，再运行通用 `tools/add_scenic.py`。该脚本映射生成端与游客端的九个景点 ID，保留 2D 的独立坐标裁切、照片署名及官方出处，不导入账号或制作历史。
