# 岐江公园 · 船厂记忆

新增游客景区 `qijiang-park`，围绕旧粤中船厂的工业遗存与滨水空间组织七处导览。

## 数据与编辑范围

- `editorial.json`：七处标题、描述、讲解、资料链接及 WGS84 导览位置。2026-10-23 核对设计团队、地方政府和中山日报资料。
- `raw/commons-metadata.json`：Commons 岐江公园分类及美术馆子分类，共 25 张候选照片的授权元数据；选用 7 张作者 EditQ 于 2023-02-28 拍摄的照片，均为 CC BY-SA 4.0。
- `photos/`、`raw/photos_final.json`：逐张查看后选定的照片及完整署名。公开照片页展示作者、日期、来源、许可证和缩略处理说明。
- `raw/14-*.pbf`：OpenFreeMap 20261018 的两个 z14 OSM 矢量瓦片，ODbL 1.0。`collect_geography.py` 解码后生成 WGS84 GeoJSON，`build_scene.py` 裁切并绘制导览图。
- 图幅 `[113.3559025,22.5167988,113.3611684,22.5222168]` 与三维坐标框架一致，是编辑图幅，不是法定边界。没有纳入周边商场、酒店、公交站等无关 POI。

旧船、美术馆采用 OSM 点位；柱阵、船坞、水塔区域、桥和步道是依据 OSM 地形与实拍定位的导览位置，不代表实地测绘。水塔采用生态岛区域点，避免宣称厘米级定位。高德 GCJ-02 只用于生成端地点搜索与范围框；不混入本地 WGS84 坐标。

## 史实边界

不推断旧船的具体船名或制造年份。琥珀水塔保留旧塔本体并加玻璃罩，骨骼水塔则因原塔结构安全问题重新制作，两者不混淆。面积、柱数、塔高等非必要数字不作无依据扩写。照片记录的是 2023 年外观，实际开放与设施现状以现场为准。

## 重新构建

```sh
python3 scenes/qijiang-park/collect_geography.py
python3 scenes/qijiang-park/build_scene.py
python3 tools/add_scenic.py scenes/qijiang-park
```

依赖：Pillow、Shapely、mapbox-vector-tile。合并脚本仅替换指定场景，保留其他景区。

## 三维制作

生成端场景 ID：`scenic-amap-b02f8018wz`。搜索时选定约 446×599 米，最终模型框架约 542×603 米。三维为依据地理资料和照片特征制作的导览模型，不是摄影测量实景重建。生成端已发布 v2，包含七处实拍、讲解和与三维坐标对齐的二维图。15 个 GLB 与 1 张纹理已按 SHA-256 校验导入，原始资源 36,698,328 字节，传输资源 4,337,488 字节（减少 88.2%）。`optimization-report.json` 记录逐文件校验值。压缩保留全部场景实例与三角形，检查包围盒误差，纹理像素无损。

游客端使用独立的 `map3d-qijiang-park-reliable-v1.js` 与资源清单，具备下载进度、超时重试、失败重载和哈希校验；所有 16 个资源成功解析后才显示就绪。原始模型保留用于重新优化。

加载流程先完成全部资源下载和校验，再解析模型和上传纹理，避免模型解析阻塞下载进度。网络阶段保留三并发、失败重试与取消。
